# Preuves (dossier d'examen)

Ce dossier contient des **copies** des artefacts du projet pour le rendu de la compétence « Préparer le déploiement d'une application sécurisée ».

- **Dockerfile**, **compose.yaml** : environnement de test et image de déploiement.
- **Cinephoria-build.yaml**, **Cinephoria-orchestration.yaml** : exemples de workflows GitHub Actions (build, orchestration).
- **load-fixtures.sh**, **generate-showtimes.sh** : scripts de préparation des données de test.
- **deploy-to-ionos.yaml** : copie d’un ancien workflow, conservée à titre d’archive ; **non utilisé** pour le déploiement.

**Déploiement cible : Railway.** La procédure complète est décrite dans `docs/04_deploiement_railway.md`.
